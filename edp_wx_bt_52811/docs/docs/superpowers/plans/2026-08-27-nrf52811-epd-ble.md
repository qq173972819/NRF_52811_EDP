# nRF52811 四色墨水屏 BLE 传图实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有 nRF52832 Beacon 工程改造成低功耗 nRF52811 BLE 四色墨水屏接收器，并把微信小程序的 NFC 传图替换为带进度和完成通知的 BLE 传图。

**Architecture:** 小程序生成固定 10,000 字节的 200×200 四色 2bpp 图像，通过自定义 GATT RX 特征按偏移可靠分包发送。nRF52811 使用纯协议状态机校验顺序和 CRC32，同时把数据流式写入屏幕控制器 RAM，校验成功才刷新；LED、电池和功耗策略由独立状态模块控制。

**Tech Stack:** Nordic nRF Connect SDK 3.3.0、Zephyr C/ztest、nRF52811 QFAA、SPIM/SAADC/GPIO、Bluetooth LE GATT、微信小程序 JavaScript/WXML/WXSS、Node.js 24 内置测试运行器。
