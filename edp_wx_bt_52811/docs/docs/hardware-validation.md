# nRF52811 + 1.54D 四色墨水屏真机验收

本清单用于用户完成编译、烧录后的真机测试。请在方框内记录结果；电流项建议填写实测值和仪表量程。

## 基础硬件

- [ ] 确认目标芯片为 nRF52811，工程目标板选择 `my_nrf52811/nrf52811`。
- [ ] 确认 1.54D 墨水屏为 200×200 四色型号。
- [ ] 按 README 引脚表核对 MOSI、CLK、CS、DC、RST、BUSY、LED、ADC 和 P0.21。
- [ ] 确认 CR2032 到 P0.02 使用两个 100 kΩ 电阻等值分压，共地可靠。
- [ ] 确认 LED 为 P0.11 高电平点亮。

## 蓝牙与小程序

- [ ] Android 微信中能搜索到 `NRF52811-EPD` 并连接。
- [ ] iOS 微信中能搜索到 `NRF52811-EPD` 并连接。
- [ ] 小程序设备列表不会重复显示同一设备，RSSI 和连接状态显示正常。
- [ ] 选择图片、裁剪、方向、抖动算法和阈值功能仍可用。
- [ ] 点击底部“发送”后显示数据发送百分比。
- [ ] 数据发送完成后显示“墨水屏刷新中”，收到完成通知后提示“刷新完成”。
- [ ] 连接断开或发送失败时，进度层能退出并允许重新连接发送。

## 图像与异常处理

- [ ] 200×200 图像方向正确，无镜像、旋转或行列错位。
- [ ] 黑、白、黄、红四种颜色与小程序预览一致。
- [ ] 接收期间 P0.11 LED 快速闪动，接收结束后熄灭。
- [ ] 传输中断后不会刷新不完整图像，重新连接可以再次发送。
- [ ] 人为发送错误 CRC 时固件拒绝数据并返回错误。
- [ ] 墨水屏 BUSY 持续异常时能在宏设定时间后退出，而不是永久卡死。
- [ ] 断电或刷新中断后再次发送完整图像可以恢复正常全刷。

## 电池和 LED

- [ ] ADC 换算电压与万用表测得 CR2032 电压基本一致（记录误差：________ mV）。
- [ ] 电压低于 `BATTERY_LOW_THRESHOLD_MV` 后，LED 按间隔三短一长闪烁。
- [ ] 电压回升超过阈值加迟滞后，低电量闪烁停止。
- [ ] 接收快闪优先于低电量提示，接收结束后 LED 先熄灭。

- [ ] 慢广播模式的广播间隔符合 `BLE_SLOW_ADV_INTERVAL_MS`。

- [ ] 图像接收电流：________ mA。
